\section{Objective}

The objective is to develop a practical framework for assessing whether a
planned experiment or a collected dataset is adequate for calibrating a sensor
for a declared use.

Adequacy is not absolute. It depends on what the sensor must measure, the
intended operating range and conditions, the calibration method, the required
performance, and the situations in which the calibrated sensor is expected to
work.

\section{Central Research Question}

\begin{quote}
Given a calibration objective, how can we determine whether an experimental
protocol or dataset provides enough appropriate evidence to develop and
evaluate a viable sensor calibration?
\end{quote}

\section{Proposed Framework}

The framework will contain two levels:
\begin{enumerate}
    \item \textbf{Universal requirements}: questions that should be considered
        in any sensor-calibration experiment.
    \item \textbf{Specific requirements}: tests that depend on the sensor
        physics, calibration model, application, and expected operating
        conditions.
\end{enumerate}

The initial candidate requirement families are:
\begin{itemize}
    \item a clearly declared calibration objective and intended use;
    \item valid sensor and reference measurements;
    \item sufficient information to learn the required relationships;
    \item adequate coverage of the intended operating domain;
    \item appropriate variation, repetitions, and experimental independence;
    \item validation without data leakage;
    \item performance and uncertainty appropriate for the application; and
    \item reproducible data collection, analysis, and reporting.
\end{itemize}

These are working categories. Each one must later be justified using existing
literature, mathematics, physical reasoning, and experimental evidence.

\section{Two Uses of the Framework}

\subsection{Before data collection}

Assess whether a proposed protocol is capable of producing the evidence needed
for calibration. This can guide the choice of trajectories, loading conditions,
repetitions, and validation runs.

\subsection{After data collection}

Assess whether the experiment actually produced a viable dataset using the
achieved reference measurements, raw sensor signals, run information, and
experimental conditions.

For each requirement, the framework should explain whether the available
evidence passes, fails, or is insufficient to decide, and why.

\section{Triaxial Sensor Case Study}

The general framework will be applied to the calibration of the triaxial force
sensor. It will be used to assess candidate combinations of calibration
trajectories, including uniaxial tests, spirals, and Lissajous curves.

The objective is not to assume that these trajectories are sufficient. The
objective is to use the framework to determine what they can identify, which
parts of the operating domain they represent, what evidence they do not
provide, and whether additional experiments are required.

\section{Proposed Work Plan}

\begin{enumerate}
    \item Confirm the objective and scope of the framework.
    \item Derive and justify the universal requirement families.
    \item Translate each requirement into practical, model- or sensor-specific
        tests.
    \item Compare candidate experimental protocols before collecting data.
    \item collect the triaxial sensor data and assess the achieved dataset; and
    \item calibrate the sensor and evaluate whether the framework's conclusions
        are supported by independent validation results.
\end{enumerate}
