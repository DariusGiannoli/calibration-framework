\section{Objective}

The objective is to develop a practical framework for assessing whether a
planned experiment or a collected dataset is adequate for calibrating a sensor
for a declared use.

Adequacy is not absolute. It depends on what the sensor must measure, the
intended operating range and conditions, the calibration method, the required
performance, and the situations in which the calibrated sensor is expected to
work.

\section{Central Research Question}

\begin{quote}
Given a calibration objective, how can we determine whether an experimental
protocol or dataset provides enough appropriate evidence to develop and
evaluate a viable sensor calibration?
\end{quote}

\section{Working Definition of Adequacy}

A dataset cannot be considered adequate in isolation. Its adequacy must be
assessed relative to a declared calibration task:
\begin{equation}
    \mathcal{T}
    =
    \left(
        \mathbf{s},
        \mathbf{q},
        \Omega,
        \mathcal{C},
        \mathcal{M},
        \mathcal{P},
        \mathcal{G}
    \right),
\end{equation}
where:
\begin{itemize}
    \item $\mathbf{s}$ is the vector of raw sensor signals used as calibration
        inputs;
    \item $\mathbf{q}$ is the reference measurand that the calibration must
        estimate;
    \item $\Omega$ is the intended operating domain;
    \item $\mathcal{C}$ is the set of relevant operating conditions;
    \item $\mathcal{M}$ is the calibration model or candidate model family;
    \item $\mathcal{P}$ is the required performance and uncertainty;
    \item $\mathcal{G}$ is the intended generalization claim.
\end{itemize}

For an acquired dataset $D$, adequacy is therefore conditional:
\begin{equation}
    \operatorname{Adequacy}\left(D \mid \mathcal{T}\right).
\end{equation}

\section{Trixial Force Sensor (under rigid mounting)}

\subsection{Adequacy Definition}
\begin{itemize}
    \item $\mathbf{s}$ is the sensor reading vector:
    \begin{equation}
        \mathbf{s}
        =
        \begin{bmatrix}
            c_1 & c_2 & c_3
        \end{bmatrix}^{\mathsf{T}},
    \end{equation}
    where $c_1$, $c_2$, and $c_3$ are the three raw coil signals.
    The vector $\mathbf{s}$ is the input of the calibration model.

    \item $\mathbf{q}$ is the reference force vector:
    \begin{equation}
        \mathbf{q}
        =
        \begin{bmatrix}
            F_x^{\mathrm{ref}} &
            F_y^{\mathrm{ref}} &
            F_z^{\mathrm{ref}}
        \end{bmatrix}^{\mathsf{T}},
    \end{equation}
    where the three force components are measured by the reference
    force/torque sensor. The vector $\mathbf{q}$ is the desired output of the
    calibration model and is used as the calibration target.

    \item $\Omega$ is the intended operating domain of the sensor. It defines the
set of three-dimensional force vectors for which the calibration is expected
to be valid:
\begin{equation}
    \Omega
    =
    [F_x^{\min},F_x^{\max}]
    \times
    [F_y^{\min},F_y^{\max}]
    \times
    [F_z^{\min},F_z^{\max}]
    \subseteq \mathbb{R}^{3}.
\end{equation}
The force limits must be selected according to the intended application.
They remain to be defined for the triaxial sensor.

\item $\mathcal{C}$ is the set of operating conditions that affect the sensor response under which the calibration is expected to be valid:
\begin{equation}
    \mathcal{C}
    =
    \mathcal{C}_{\mathrm{mount}}(rigid)
    \times
    \mathcal{C}_{\mathrm{temperature}}
    \times
    \mathcal{C}_{\mathrm{rate}}.
\end{equation}

The relevant temperature and loading-rate ranges remain to be defined.

\item $\mathcal{M}$ is the calibration model or candidate model family defining the mathematical mappings considered for converting the sensor signals
$\mathbf{s}$ into an estimated force vector $\widehat{\mathbf{q}}$:
\begin{equation}
    \mathcal{M}
    =
    \left\{
        f_{\boldsymbol{\theta}} :
        \mathbf{s} \mapsto \widehat{\mathbf{q}}
        \;\middle|\;
        \boldsymbol{\theta} \in \Theta
    \right\},
\end{equation}
where $\boldsymbol{\theta}$ represents the model parameters and $\Theta$ is
their allowed parameter space.

The first candidate model is an affine linear calibration:
\begin{equation}
    \widehat{\mathbf{q}}
    =
    \mathbf{A}\mathbf{s}+\mathbf{b},
\end{equation}
where $\mathbf{A}\in\mathbb{R}^{3\times3}$ represents the sensor sensitivities
and cross-axis relationships, and $\mathbf{b}\in\mathbb{R}^{3}$ represents the
zero-force offsets.

More complex model families will be considered only if the simpler models are
shown to be inadequate.

\item $\mathcal{P}$ is the set of required calibration-performance and
uncertainty limits. For validation sample $i$, the force-estimation error is
\begin{equation}
    \mathbf{e}_i
    =
    \widehat{\mathbf{q}}_i-\mathbf{q}_i.
\end{equation}

For axis $j\in\{x,y,z\}$, the root-mean-square error is
\begin{equation}
    \operatorname{RMSE}_j
    =
    \sqrt{
        \frac{1}{N_{\mathrm{val}}}
        \sum_{i=1}^{N_{\mathrm{val}}}
        e_{i,j}^{2}
    },
\end{equation}
where $N_{\mathrm{val}}$ is the number of independent validation samples.

An initial definition of the performance requirements is
\begin{equation}
    \mathcal{P}
    =
    \left\{
        \operatorname{RMSE}_j \leq \varepsilon_j,
        \quad
        U_j \leq U_j^{\max}
        \;:\;
        j\in\{x,y,z\}
    \right\},
\end{equation}
where $\varepsilon_j$ is the maximum acceptable error and $U_j^{\max}$ is the
maximum acceptable uncertainty for force axis $j$.

The numerical limits remain to be defined from the application requirements.

\item $\mathcal{G}$ is the intended generalization claim. It defines the unseen
runs, operating conditions, or physical sensor units for which the calibration
is expected to remain valid:
\begin{equation}
    \mathcal{G}
    \subseteq
    \mathcal{R}
    \times
    \mathcal{C}
    \times
    \mathcal{U},
\end{equation}
where $\mathcal{R}$ is the set of experimental runs, $\mathcal{C}$ is the set
of operating conditions, and $\mathcal{U}$ is the set of physical sensor units.

For the first calibration stage, the intended claim is generalization to new
runs of the same individual sensor under the declared operating conditions:
\begin{equation}
    \mathcal{G}_{\mathrm{stage\,1}}
    =
    \mathcal{R}_{\mathrm{new}}
    \times
    \mathcal{C}
    \times
    \left\{u_0\right\},
\end{equation}
where $u_0$ is the individual sensor being calibrated.





\end{itemize}
